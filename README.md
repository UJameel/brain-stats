# brain-stats

`stats.json` holds counts, dates and fixed labels derived from my personal
knowledge base: how many items it holds, when it runs, how it is shaped.

It contains no note content. No titles, no topics, no text, no search
queries, no file paths beyond a fixed list of five folder names. The
generator never opens a note, and validates every field by position before
writing — it refuses to write a file containing any string that is not a
known label or an ISO date.

Updated nightly at 03:00 by the system it describes. Consumed by a page
that visualises it.
